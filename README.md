# Java Classes and Objects

## 📌 About

This repository contains my learning and practical implementation of **Classes and Objects in Java**.

To understand these concepts through practical application, I developed two small real-world Java projects:

1. 🏦 **Bank Account Management**
2. 🍔 **Online Food Delivery System**

These projects helped me understand how real-world entities can be represented using Java classes and objects.

---

# 🏦 Project 1: Bank Account

## 📖 Description

The **Bank Account** project is a simple Java program that represents a bank account using a class and objects.

The project models a real-world bank account and performs basic account operations.

## ⚙️ Features

- Create a bank account
- Store account holder details
- Store account balance
- Deposit money
- Withdraw money
- Display account information
- Check account balance

## 🧱 Main Class

### `BankAccount`

The `BankAccount` class represents a bank account.

### Object Example

```java
BankAccount account1 = new BankAccount();
```

Here, `account1` is an object of the `BankAccount` class.

## 💡 Concepts Practiced

- Class creation
- Object creation
- Instance variables
- Methods
- Accessing object data
- Calling methods through objects
- Real-world object modeling

# 🍔 Project 2: Online Food Delivery

## 📖 Description

The **Online Food Delivery** project is a simple Java program that models an online food ordering system.

The project represents food-order information using Java classes and objects.

## ⚙️ Features

- Store customer information
- Store food item information
- Store food price
- Create a food order
- Display order details
- Calculate/display order information

## 🧱 Main Class

### `FoodOrder`

The `FoodOrder` class represents a food order in the system.

### Object Example

```java
FoodOrder order1 = new FoodOrder();
```

Here, `order1` is an object of the `FoodOrder` class.

## 💡 Concepts Practiced

- Creating classes
- Creating objects
- Defining object properties
- Defining object methods
- Accessing object data
- Calling methods using objects
- Modeling a real-world system
